I. List Boxes

1. Licensee Name / Club📜 (Yellow Listbox)
Execute the SQL script below in SSMS to see the exact data displayed in the Yellow Listbox. 


SELECT 
    ID, 
    Name,  
    '(' + SUBSTRING(Phone1, 1, 3) + ') ' + SUBSTRING(Phone1, 4, 3) + '-' + SUBSTRING(Phone1, 7, 4) AS Phone, 
    LTRIM(RTRIM(Address1)) + ', ' + LTRIM(RTRIM(City)) + ', ' + LTRIM(RTRIM(St)) + ' ' + LTRIM(RTRIM(Zip)) AS googleAdd 
FROM Club 
WHERE NonLiquor = 0 
ORDER BY Name;

2. Order / Invoice 📘 (Blue Listbox)
Execute the SQL script below in SSMS to see the exact data displayed in the Blue Listbox.
The original data source, which was an Access query, has been converted to run in SSMS. 


WITH qryClubOrderLineTotals_A AS (
    SELECT  
        ol.OrdheadID,         
        SUM(CASE WHEN sd.ID = 1 THEN ol.Price * QuantityShipped ELSE 0 END) AS LiquorExtPrice,
        SUM(CASE WHEN sd.ID <> 1 THEN (ol.Price - ol.BuyDown) * ol.QuantityShipped ELSE 0 END) AS NonLiquorExtPrice,
        CASE WHEN c.ApplyDiscount = 1 THEN s.ClubDiscRate ELSE 0 END AS LiquorDiscountRate,
        SUM(CASE WHEN sd.ID <> 1 THEN CASE WHEN sd.AllowClubDiscounts = 1 THEN (ol.Price - ol.BuyDown) * ol.QuantityShipped ELSE 0 END ELSE 0 END) AS NonLiquorExtPriceDiscountable,
        CASE WHEN c.ApplyDiscount = 1 THEN s.NonClubDiscRate ELSE 0 END AS NonLiquorDiscountRate
    FROM Sysfile s
    CROSS JOIN Club c
    INNER JOIN OrdHead oh ON c.ID = oh.ClubID 
    INNER JOIN OrderLine ol ON oh.ID = ol.OrdheadID 
    INNER JOIN Item i ON ol.ItemID = i.ID 
    INNER JOIN SalesDepartment sd ON i.SalesDepartmentID = sd.ID 
    GROUP BY ol.OrdheadID, CASE WHEN c.ApplyDiscount = 1 THEN s.ClubDiscRate ELSE 0 END, c.NonLiquor, CASE WHEN c.ApplyDiscount = 1 THEN s.NonClubDiscRate ELSE 0 END
), qryClubOrderLineTotals_B AS (
    SELECT 
        OrdheadID,
        LiquorExtPrice,
        NonLiquorExtPrice,
        CASE WHEN (LiquorExtPrice * LiquorDiscountRate) - FLOOR(LiquorExtPrice * LiquorDiscountRate) > 0.5 THEN CEILING(LiquorExtPrice * LiquorDiscountRate) ELSE FLOOR(LiquorExtPrice * LiquorDiscountRate) END / 100.0 AS LiquorDiscount,
        CASE WHEN (NonLiquorExtPriceDiscountable * NonLiquorDiscountRate) - FLOOR(NonLiquorExtPriceDiscountable * NonLiquorDiscountRate) > 0.5 THEN CEILING(NonLiquorExtPriceDiscountable * NonLiquorDiscountRate) ELSE FLOOR(NonLiquorExtPriceDiscountable * NonLiquorDiscountRate) END / 100.0 AS NonLiquorDiscount
    FROM qryClubOrderLineTotals_A
), qryClubOrderLineTotals AS (
    SELECT 
        OrdheadID,
        [LiquorExtPrice] + [NonLiquorExtPrice] AS ExtPrice,  
        [LiquorDiscount] + [NonLiquorDiscount] AS ExtDiscount 
    FROM qryClubOrderLineTotals_B
)       
SELECT  
    oh.ID,
    CASE WHEN (q.ExtPrice - q.ExtDiscount) = OrdDollars THEN c.Name ELSE '**** REPRINT **** ' + c.Name END AS ClubName,
    RIGHT('0' + CAST(MONTH(InvDate) AS VARCHAR), 2) + '/' + RIGHT('0' + CAST(DAY(InvDate) AS VARCHAR), 2) AS [Date],
    oh.InvoiceNo AS [Invoice #], 
    q.ExtPrice - q.ExtDiscount AS Amount, 
    oh.PaidFlag, 
    c.ID 
FROM Club c
INNER JOIN OrdHead oh ON c.ID = oh.ClubID 
INNER JOIN qryClubOrderLineTotals q ON oh.ID = q.OrdheadID 
ORDER BY CASE WHEN (q.ExtPrice - q.ExtDiscount) = OrdDollars THEN c.Name ELSE '**** REPRINT **** ' + c.Name END, RIGHT('0' + CAST(MONTH(InvDate) AS VARCHAR), 2) + '/' + RIGHT('0' + CAST(DAY(InvDate) AS VARCHAR), 2) + '/' + RIGHT(CAST(YEAR(InvDate) AS VARCHAR), 2)

II. Command Buttons

1. Process e-Mails 📩

This will open the ClubOrderXLImport form.

Execute the SQL script below in Access Query Window to see the exact data displayed in the form.

The SQL script can't be executed in SSMS because the ClubOrderXL table is a local Access table.

Clicking the Create dispensers order button will ...


SELECT 
    ClubOrderXL.line AS LineID, 
    ClubOrderXL.ItemID, 
    IIf(IsNumeric([Qty]),[Qty],0) AS QuantityOrdered, 
    IIf(IsNumeric([Qty]),[Qty],0) AS QuantityShipped, 
    Item.Price, Item.Cost, 
    ClubOrderXL.ClubID, 
    ClubOrderXL.ClubName, 
    ClubOrderXL.StoreName
FROM ClubOrderXL 
INNER JOIN Item ON ClubOrderXL.ItemID = Item.ID;
